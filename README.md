# Fight Game

## Overview
Fight Game is a C++ console-based fighting game that allows players to engage in thrilling combat scenarios. Players can choose their characters, execute various attacks, and experience dynamic battles in a text-based environment.

## Features
- **Character Selection**: Choose from multiple fighters, each with unique abilities and styles.
- **Combat Mechanics**: Engage in turn-based fighting where strategy and skill determine the winner.
- **Health Management**: Keep track of health points and manage attacks wisely to defeat opponents.

## Installation
To run the Fight Game:
1. Clone the repository:
   ```bash
   git clone https://github.com/hakimov-vs/Fight-game.git
   ```
2. Navigate into the project directory:
   ```bash
   cd Fight-game
   ```
3. Compile the source code:
   ```bash
   g++ main.cpp -o fightgame
   ```
4. Run the game:
   ```bash
   main.exe
   ```

## How to Play
- Follow the on-screen instructions to begin your fights.
- Select your character and prepare to battle.
- Use the keyboard to make decisions and perform actions during the game.
